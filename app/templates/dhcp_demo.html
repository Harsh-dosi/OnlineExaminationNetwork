📖 DHCP DORA Process Explained

1DISCOVER

Client broadcasts (255.255.255.255) on UDP :68→:67, requesting IP configuration.

→
2OFFER

Server responds with offered IP, subnet, gateway, DNS, and lease duration on UDP :67→:68.

→
3REQUEST

Client broadcasts acceptance, formally requesting the offered IP address.

→
4ACKNOWLEDGE

Server confirms the lease, committing the IP→MAC binding for the lease duration.
