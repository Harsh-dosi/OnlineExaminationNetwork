📖 How DNS Resolution Works

1. Query

Client asks: "What is the IP of exam.local?" (UDP port 53)

→
2. Cache Check

Resolver checks its cache for a recent answer within TTL window.

→
3. Zone Lookup

If cache miss, query is forwarded to authoritative zone database.

→
4. Response

NOERROR (with IP) or NXDOMAIN (not found) is returned and cached.

Real vs Simulated: A real DNS lookup generates UDP packets visible in Wireshark with dns display filter. This simulation uses a Python database lookup — no actual UDP packets are generated. For exam.local to resolve in a real browser, you would need a hosts-file entry or a real local DNS server.
